# CHEVALET — презентационная веб-версия

Первый этап по ТЗ 1.1 с последующими правками заказчика. HTML, CSS и JavaScript без фреймворка, сборки и CDN. Для плавной прокрутки подключён локальный Lenis 1.3.27. Основные рендеры взяты из предоставленного PDF. Сайт не опубликован и не подключён к Tilda.

Актуальные изменения: [CHANGELOG.md](CHANGELOG.md). Главный кадр теперь `interior-04.webp`, а рендер с подсвеченной аркой `interior-01.webp` используется в секции трансформации. Фирменный логотип подключён из предоставленного Arista Pro Extra Light. Телефон: +7 (123) 456-78-90, часы: ежедневно 10:00–00:00. Эти данные внесены по указанию пользователя.

## Просмотр

Для просмотра достаточно открыть `index.html` двойным щелчком. Все необходимые материалы находятся в проекте, интернет для просмотра не нужен (кроме перехода в карту).

Для проверки через локальный HTTP-сервер выполните в папке проекта:

```sh
node scripts/serve.mjs
```

Откройте http://127.0.0.1:4173. Альтернатива: `npm start`. Для сервера нужен Node.js 20.11+ (рекомендуется 22+). Остановка — Ctrl+C в терминале. Скрипты разделены по ответственности и изолированы; данные передаются через единое пространство имён `ChevaletContent`. Они также работают при открытии HTML без сервера.

- Русский: http://127.0.0.1:4173/?lang=ru
- Français: http://127.0.0.1:4173/?lang=fr
- Проверка файлов и переводов: `npm run check`.
- Перегенерация временных страниц меню: `npm run assets`.

## Реализовано

- Первый экран с настоящим рендером центральной подсвеченной арки.
- Закрепление и синхронное уменьшение фонового кадра и элементов хиро. Девять изображений собираются в сетку 3 × 3 с промежутком 15 px, без fade-in. Средние верхний/нижний кадры идут вертикально, угловые следуют немного позже с лёгким смещением к центру. Блюр и исчезновение элементов синхронизированы; текст вступления появляется отдельной последующей фазой. Прокрутка обратима.
- Бесконечная галерея с мягким торможением при наведении, увеличением и просмотром по касанию. Перетягивание пальцем или с зажатой левой кнопкой мыши; вертикальная прокрутка страницы сохраняется. Отдельная кнопка паузы.
- Два независимых набора страниц кухни и бара, тонкие SVG-стрелки по бокам, один счётчик, свайп, полноэкранный просмотр, дополнительное увеличение и прокрутка увеличенного листа. При переключении листы по очереди уходят вниз с блюром, затем новые последовательно появляются; скрытый второй лист на телефоне не участвует. Вступительный текст — один абзац из пяти строк в RU/FR.
- Атмосферный закреплённый кадр, который сужается и превращается в арку; боковые фотографии с подписями.
- Навигационная шторка сверху с блокировкой фоновой прокрутки, управлением фокусом, Escape и скруглённой кнопкой бронирования.
- Полный набор текстов RU/FR, включая меню, окна и подписи изображений; язык сохраняется в URL, работают переходы назад/вперёд.
- Демонстрационное окно бронирования без отправки данных, согласно пункту 10 ТЗ.
- Контакты и иллюстративная карта города без кнопки перехода к карте.
- Футер закреплён за основным полотном страницы и постепенно открывается из-под контактов; слишком высокий футер остаётся доступным для прокрутки. Часы работы находятся в навигации и контактах, в хиро их нет.
- Локальные изображения и шрифты; адаптация в диапазонах Tilda 1200 / 960 / 640 / 480 / 320; режим reduced motion.

## Материалы и точность бренда

Для логотипа используется предоставленный `AristaPro-ExtraLight.ttf`, скопированный в `assets/` и подключённый локально. Manrope также хранится локально. Декоративный Glanz пока заменён открытым Cormorant Garamond. После получения Glanz в веб-формате заменить семейство в `:root` и `assets/fonts.css`. Права на предоставленный фирменный шрифт подтверждаются владельцем перед публикацией. Лицензии открытых шрифтов и Lenis включены в `assets/`.

Все блюда, напитки и цены в демонстрационных листах — иллюстративные. Каждый лист подписан. Перед запуском заменить утверждёнными страницами меню кухни и бара на RU/FR. SVG-файлы можно заменить JPG/WebP, обновив `pageSrc()` в `js/app.js` и количество страниц. Отдельные PDF для скачивания добавляются после получения оригиналов.

Фотографии `interior-*.webp` извлечены из пользовательского файла `2024_12_30_Визуализации (2).pdf` и оптимизированы до 1920 px. Остальные извлечённые рендеры сохранены как запас материалов; сайт загружает только используемые.

## Что требуется от заказчика перед запуском

1. Утвердить адрес и социальные сети; подтвердить перед запуском заданные пользователем телефон и часы. Иллюстративная карта показывает город, не вымышленную точку ресторана.
2. Предоставить Glanz в веб-формате и подтвердить лицензии фирменных шрифтов.
3. Предоставить актуальные меню на двух языках и финальные фотографии блюд.
4. Выбрать сервис бронирования. Заменить обработчик `showInfo('booking')` переходом или открытием виджета. Все CTA отмечены `data-book`; событие `chevalet:booking` содержит источник и язык для будущей аналитики.
5. Предоставить юридические реквизиты и документы. Текущий информационный диалог описывает только презентационную версию.
6. После выбора домена настроить canonical, hreflang, абсолютный OG image, sitemap, robots и аналитику. Для презентации метаданные RU/FR меняются вместе с языком; полноценная индексация раздельных языковых URL выполняется при переносе.

## Перенос на Tilda

Композиции разделены по секциям `home`, `about`, `gallery`, `menu`, `atmosphere`, `contacts`. На Tilda создать отдельные языковые страницы `/` и `/fr/`, а тексты перенести из `content.js`. Семантическую разметку можно переносить блоками в T123 или воспроизводить штатными элементами Zero Block.

Сохранить CSS-токены и классы сложных композиций. JS подключать после разметки в порядке `content.js` → `menu-motion.js` → `gallery-drag.js` → `app.js` (Lenis — перед ними); пути к изображениям и шрифтам заменить на Tilda CDN. Не применять стандартные анимации Tilda одновременно с JS к одним и тем же элементам.

Первый экран и арочная секция используют нативный `position: sticky`, а прогресс связан с фактической прокруткой. Не помещать их внутрь предков с `overflow: hidden/auto` или CSS-transform. Высоту внешних секций сохранить; отдельные sticky-части работают внутри них. Галерею, меню и диалоги можно перенести независимыми HTML-модулями.

## Проверка

Проверяются ссылки на локальные файлы, наличие всех листов меню и полнота языковых словарей. В браузере проверены основные интерактивные сценарии, загрузка изображений и отсутствие ошибок консоли. Окончательная проверка Safari/iOS и реальных мобильных устройств, подключения бронирования и SEO нужна после переноса и получения финального контента.
